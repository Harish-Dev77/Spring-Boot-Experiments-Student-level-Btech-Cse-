# Spring Boot Experiments - B.Tech CSE (Student Level)

Welcome to the collection of Spring Boot experiments designed specifically for B.Tech Computer Science students. These projects cover fundamental and advanced concepts in a simple, easy-to-understand manner, perfect for university vivas and practical exams.

## 🚀 Experiments Included

| Exp # | Project Name | Description & Key Concepts |
|---|---|---|
| **2** | `exp2-hello-world` | Basic `@RestController` printing "Hello World". |
| **3** | `exp3-dependency-injection` | Inversion of Control (IoC) using Constructor and Setter Injection. |
| **4** | `exp4-restful-services` | Basic REST API using in-memory Java collections. |
| **5** | `exp5-exception-handling` | Global Exception Handling using `@ControllerAdvice`. |
| **6** | `exp6-jpa-crud` | Full CRUD operations using Spring Data JPA and H2 Database. |
| **7** | `exp7-security-roles` | Spring Security basics: Authentication & Role-Based Authorization. |
| **8** | `exp8-multi-database` | Configuring Spring Boot to connect to two different databases. |
| **9** | `exp9-unit-testing` | Unit testing services and controllers using JUnit 5 and Mockito. |
| **10** | `exp10-tdd-integration` | Test-Driven Development (TDD) and Integration Testing. |
| **11** | `exp11-bank-system` | A robust Bank System REST API with proper HTTP verbs. |
| **12** | `exp12-bank-branch-services` | A microservice managing Bank Branches and IFSC codes. |
| **13** | `exp13-student-management` | Jakarta Validation (`@Valid`, `@Email`) and Custom Exceptions. |
| **14** | `exp14-http-status-codes` | Mapping specific custom exceptions to exact HTTP status codes. |
| **15** | `exp15-realtime-sse` | Real-time browser notifications using Server-Sent Events (SSE). |

## 🛠️ Tech Stack
* **Java:** 17
* **Spring Boot:** 3.2.3
* **Database:** H2 (In-memory)
* **Build Tool:** Maven

## 🏃 How to Run
Each experiment is a standalone Spring Boot Maven project. To run any experiment:
1. Open the specific experiment folder in your IDE (VS Code, IntelliJ, or Eclipse).
2. Run the main application class (e.g., `*Application.java`).
3. Access the endpoints via `http://localhost:8080`.
